\begin{frame}{Időkomplexitás bizonyítása (1.)}
  \small
  \begin{block}{Tétel:}
    % Given the Minimum Spanning Tree for an undirected, weighted graph G = (V,E), and non-tree edges sorted by weight, then Algorithm 1 finds all minimum cost replacement edges of the Minimum Spanning Tree of G in O(m+ n) time and O(m+ n) space.
    Adott egy irányítatlan, súlyozott $G = (V, E)$ gráf minimális feszítőfája, és a nem feszítőfabeli élek súly szerint rendezve, akkor az algoritmus $ \bigO ( m + n )$ időben és $ \bigO ( m + n )$ helyigény mellett megkeresni $G$ minimális feszítőfájának összes minimális költségű csereélét.
  \end{block}
  \textbf{Bizonyítás:}\\
  Legyen T a G gráf minimális feszítőfája.
  \begin{itemize}
    \item 1. A P szülő tömb inicializálása: $ \bigO (n) $
    % \item Since there are n - 1 edges in T then running DFS on T to initialize the IN and OUT arrays takes $ \bigO (n) $ time.
    \item 2. Mivel T-ben n - 1 él van, ezért a DFS lefuttatása T-n az IN és OUT értékek inicializálásához: $ \bigO (n) $.
    % \item Initializing the replacement edges of the MST edges takes $ \bigO (n) $ time.
    \item 3. Csereélek inicializálása minden MST élhez: $ \bigO (n) $ idő.
    % \item There are m - n + 1 = O(m) non-MST edges read in ascending order by weight, taking O(m) time.
  \end{itemize}
\end{frame}

\begin{frame}{Időkomplexitás bizonyítása (6.)}
  \begin{block}{4. Állítás:}
    % Algorithm 1 updates disjoint sets in O(m + n) time and O(n) space.
    Az algoritmus $ \bigO (m + n) $ időben és $ \bigO (n) $ tárhellyel frissíti a diszjunkt halmazokat.
  \end{block}
  \begin{itemize}
    % \item 6. It follows from Claim 3 and this specific ordering of the disjoint set labels that the algorithm cannot follow a path that does not close the cycle.
    \item 6. A 3. állításból és az előzőekben bemutatott diszjunkt halmaz műveleti sorrendek miatt az algoritmus csak olyan utat követ, ami bezárj a kört.
    % \item 7. Then because of path compression only O(m) edges are traversed, taking O(m) time. 
    \item 7. Az útkompresszió miatt csak $ \bigO (m) $ élet járunk be, ami $ \bigO (m) $ idő.
    % \item 8. Claim 4 establishes O(m + n) time and O(n) space for all disjoint set operations. Hence it takes O(m+ n) time to find all replacement edges in T. 
    \item 8. A 4. állítás szerint az összes művelete a diszjunkt halmazokon $ \bigO (m + n) $ időkomplexitással és $ \bigO (n) $ tárhelykomplexitással jár. Ezért $ \bigO (m + n) $ időkomplexitással találjuk meg a csereéleket T-hez.
    % \item 9. The data structures are simple arrays and Gabow-Tarjan disjoint set union data structures, taking O(n) space, and all non-MST edges take O(m) space. Therefore it takes O(m+ n) time and O(m+ n) space as claimed.
    \item 9. A használt adatszerkezetek: tömbök és Gabow-Tarjan diszjunkt halmaz adatszerkezetek, amik $ \bigO (n) $ tárhely. Továbbá, az összes nem-MST él $ \bigO (m) $ tárhely. Így igaz az előzőekben állított $ \bigO (m + n) $ időkomplexitás és $ \bigO (m + n) $ tárhelykomplexitás. $ \square $
  \end{itemize}
